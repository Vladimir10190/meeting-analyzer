# AI-анализатор видеовстреч

Локальное учебное приложение для обработки записей MP4 и WebM. Оно извлекает аудио через FFmpeg, распознаёт речь через OpenAI и составляет конспект по готовой расшифровке. История хранится в `data/meetings/`. Для каждой встречи сохраняются исходное имя файла, время загрузки, статус, расшифровка и конспект.

## Запуск в Windows PowerShell

1. Установите Node.js 22 или новее и FFmpeg с FFprobe. Сделайте оба инструмента доступными через `PATH`. Можно указать полные пути в `.env.local` через `FFMPEG_PATH` и `FFPROBE_PATH`.
2. Откройте PowerShell в папке проекта и выполните:

   ```powershell
   node --version
   ffmpeg -version
   ffprobe -version
   Copy-Item .env.example .env.local
   notepad .env.local
   ```

3. Заполните `OPENAI_API_KEY` действующим ключом OpenAI API с доступом к моделям. При необходимости измените `STT_MODEL` и `SUMMARY_MODEL`. Переменные процесса имеют приоритет над файлом.
4. Запустите сервер и откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

   ```powershell
   node server.mjs
   ```

Для остановки нажмите Ctrl+C. Запускайте один экземпляр сервера из этой папки. Установка пакетов npm не требуется. Без ключа можно открыть страницу и просматривать ранее сохранённые встречи.

## Использование и проверки

Выберите видео с разборчивой русской речью. Обработка начнётся автоматически. На той же странице отображается результат и история. Можно загрузить один файл до 250 МиБ и продолжительностью до пяти минут. Пустые, повреждённые и беззвучные записи приводят к ошибке с возможностью выбрать файл повторно. При тишине применяется проверка громкости, качество распознавания речи зависит от записи и модели.

Приложение временно сохраняет исходное видео рядом с историей, чтобы извлечь аудио. После обработки временные файлы удаляются. Аудиодорожка и расшифровка передаются в OpenAI. Доступ к API требует сети и может тарифицироваться отдельно.

Запустите проверки сервера командой `node --test`. Они используют тестовый обработчик вместо вызовов OpenAI. Для ручной приёмки загрузите MP4 с явно названным решением и поручением, затем WebM с обсуждением без договорённостей. Сравните расшифровку и все четыре блока с тем, что прозвучало. Обновление страницы и перезапуск сервера должны сохранить результаты. Даже если вкладка закрыта, запущенная обработка продолжится, пока сервер работает.

## Повторное использование

`analysis.mjs` экспортирует `processVideo(videoPath)`. Функция принимает путь к локальному видео и возвращает промис с `{ transcript, summary }`. Её можно вызывать из серверного кода без HTTP и без истории. Удаление переданного файла остаётся за вызывающим кодом. При прямом вызове задайте конфигурацию через переменные процесса или запустите скрипт командой `node --env-file=.env.local script.mjs`.

Документация OpenAI по [распознаванию речи](https://developers.openai.com/api/docs/guides/speech-to-text) и [структурированному выводу](https://developers.openai.com/api/docs/guides/structured-outputs).
